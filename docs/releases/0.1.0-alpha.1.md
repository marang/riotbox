# Riotbox 0.1.0-alpha.1 — source evaluation alpha

First source-only prerelease for private non-commercial local evaluation under
the [source-available LICENSE](../../LICENSE). This is a playable prototype,
**not a stage-ready or production-qualified instrument**.

## Included

- Existing source → capture → gestures → recording → save/restore workflow.
- Final-stop envelope, preset/Undo barriers and post-overflow drum scheduling
  corrections (RIOTBOX-1604, 1605, 1606).
- Already-merged session/graph, path and WAV identity/alignment hardening and
  bounded recovery/identity fixes.
- Security maintenance; compatible CPAL 0.18.2, quick-xml 0.42.0, SHA-2 0.11.1
  updates and the documented narrow vendored DAWproject correction.

## Build and start

Use Linux, current stable Rust/Cargo (edition 2024), Python 3 and ALSA development
libraries/pkg-config. The attached evidence records exact local tool versions;
no older MSRV is claimed. Debian/Ubuntu build prerequisites include
`libasound2-dev` and `pkg-config`; Arch uses `alsa-lib` and `pkgconf`.

Verify SHA256SUMS, extract the source archive, then in its root:

```sh
cargo build --locked --release -p riotbox-app --bin riotbox-app
./target/release/riotbox-app --help
```

Help currently prints usage with a nonzero exit, before audio initialization.
For an intentional instrument run with your own permitted WAV, follow
[Start Here](../../README.md#start-here) and [jam recipes](../jam_recipes.md).
No source recordings are bundled. The core instrument requires no DAW;
export/DAW capabilities remain bounded by the existing recipes.

## Qualification and known limitations

The release evidence manifest records actual technical gates, source-package
build and identities. Synthetic callback and Development regression checks
are **not human listening or physical host qualification**. Historical RIOTBOX-1475
covered six families for a bounded demo, not general 1.0 readiness; its human
verdicts are not newly transferred to this release's artifacts.

- Formats/interfaces remain alpha. Back up sessions/captures; never use this
  build as the sole copy of a live performance.
- RIOTBOX-1607 remains open: edited/malformed snapshots can carry provenance
  after the restore cursor. Avoid untrusted/manually edited snapshot payloads.
  Normal Save was not demonstrated to produce this condition.
- Real-device latency, endurance, recovery rehearsal and the original ALSA
  environment issue are not qualified by this distribution.
- Full DAW arrangement/export and polished platform packaging remain open.
  No installers or qualified Windows/macOS instrument binaries are supplied.
- No new musical-quality, source-generalization, hardness, Holdout or demo
  acceptance is claimed. No private samples, commercial references or generated
  review audio are distributed. Tiny committed WAV identity-test placeholders
  are not demos.

The [release contract](../workflow/source_evaluation_release.md) defines gates
and reuse boundaries; RIOTBOX-1038/1039/1041/1036 remain open for larger requirements.
